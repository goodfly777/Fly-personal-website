# 首页视觉体系统一

## 实现

- 首页黑色星空、深蓝表面、淡紫色强调色提取至 `src/framework/theme.css`，Tailwind 提供语义颜色类。
- 迁移项目列表、两类项目详情、博客列表/正文、摄影、关于/简历、留言与后台管理模块。
- 导航、页尾、按钮、输入、卡片、评论、Markdown 表格/引用和 Mermaid 图表共用主题。
- 移除 background.css 按背景类猜测文本颜色的覆盖规则，主题变量对 portal 弹窗同样有效。
- 保留后台紧凑布局、编辑器高度、路由和业务操作；发布/审核通过使用绿色，警告和错误保留独立状态色。

## 验证

- `npm run build` 通过（包含 TypeScript 检查）。
- `node --test` 执行 src、scripts 中全部 24 个 .test.mjs 文件，通过。
- 8 个原有源代码回归测试更新了颜色类定位条件，业务断言保留。
- 浏览器查看首页、项目列表、博客列表、摄影空列表、关于、留言、两个项目详情及后台登录。
- 390×844 移动端检查留言表单、导航展开和两个项目详情；1440×900 桌面端检查关于页导航和后台登录表单。所检查页面未出现文档水平溢出。
- 客服项目图片预览弹窗可打开；图片本身缺失，未验证实际图片显示效果。

## 限制

- 当前检出缺少部分 docs/images 中的头像、项目截图、Logo 与微信二维码文件。构建会给出资源警告，页面可能显示破图；本次未替换内容资产。
- 摄影没有可用照片，未验证有数据时的瀑布流及灯箱。
- 未登录后台，六个管理模块和保存、上传、审核等操作仅完成源代码样式迁移及已有回归检查，未进行浏览器端到端验证。
- 未覆盖所有博客正文、Mermaid 实例及所有错误分支的浏览器验证。
- 构建保留现有大分块告警；未引入依赖，未部署。
