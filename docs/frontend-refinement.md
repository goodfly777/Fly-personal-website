# 前端改版：导航、首页与反馈状态

本轮在现有未提交改动上继续修改，未提交或部署。

| 原问题 | 本轮修改 | 目的 |
| --- | --- | --- |
| 首页隐藏全站导航 | 首页恢复导航，桌面品牌与菜单分区，手机使用折叠菜单 | 博客、关于、简历等入口直接可达 |
| 章节入口占据首屏顶部 | 章节切换移至底部，保留全屏章节模式 | 区分全站路由与页内浏览 |
| 首屏无照片时显示黑框 | CSS 原创轨道图形作为缺图状态，成功读取照片后仍显示照片 | 不依赖额外图片资源也保持完整构图 |
| 标题、正文与按钮权重接近 | 重排标题层级、文字宽度、按钮样式、卡片留白 | 明确人物身份与主要浏览路径 |
| 请求失败被当作文章为空 | 独立失败状态与重试入口 | 反馈真实状态并提供恢复操作 |
| 首页 CSS 多次覆盖 | 合并为单一组件样式及响应式规则 | 降低修改时的规则冲突 |
| 手机菜单只能点击关闭 | 支持 Escape 关闭、焦点返回按钮、路由变化收起 | 改善键盘与路由操作 |

## 已完成验证

- TypeScript 与 Vite 生产构建通过。
- 原有 src、scripts 下 24 个测试文件全部通过。
- 本地页面 HTTP 200。
- 浏览器检查 1440×900 桌面首屏、项目章节切换。
- 浏览器检查 390×844 文章请求失败与重试、菜单展开、Escape 关闭并恢复焦点、从菜单进入项目页并自动收起。
- 未登录后台，未修改后端数据。

## 仍需正视的限制
