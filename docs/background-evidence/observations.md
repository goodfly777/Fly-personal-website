# 全站颗粒背景：参考与实现记录

参考：https://candycode.com/ 。会话日期：2026-10-31（Asia/Shanghai）。本次只修改本地源码，未部署。

## 证据来源与对照

| 对象 | 已确认参考表现／来源 | 原实现差异 | 本次改动 |
| --- | --- | --- | --- |
| 造型 | 浏览器截图：黑底、大量低亮微点、少量中点和极少大灰点 | 原本也是圆点，但尺寸/亮度缺少统一配置 | 灰白圆点，集中配置 97%/2.5%/0.5% 世界尺寸分布，无光晕或拖尾 |
| 运动 | 用户确认：连续纵深运动 | 原实现含纵深，也含鼠标视差和闪烁 | 固定世界坐标与连续 z，透视投影，深度按有效时间推进 |
| 鼠标／滚动 | 用户确认：不驱动背景，不改变方向/速度/深度 | 原来存在 pointermove/pointerout/blur 关联 | 背景只监听 resize、visibilitychange 和动态偏好，无指针和滚动输入 |
| 区域切换 | 用户确认：背景持续运行，不生成新背景，不参加转场；浏览器确认 Work 区段仍有颗粒 | 原实例从首页挂载 | 挂载在 App 的 Suspense/Routes 之外，与内容动画分离 |
| 亮度 | 用户确认：不主动闪烁 | 原来相位/频率驱动亮度变化 | 移除时间振荡；透明度过渡只隐藏远端生成、近端回收和屏幕边缘回收 |
| 手机 | 参考截图 390×844，背景覆盖首屏与下方区段 | 原来与桌面共用数量策略 | 手机数量与像素比独立配置；保留幸存颗粒及深度，调整画布和投影 |
| 内容插图 | 卡牌、叠卡、横向客户卡片属于内容 | 不应迁移成装饰 | 未复制插图，未重做页面布局 |

## 文件与实现

- `src/components/background/Starfield.tsx`：共享画布、连续深度、确定性随机状态、边界回收、尺寸更新、单 RAF、暂停恢复与清理。`data-starfield-instance` 用于验证挂载连续性。
- `src/components/background/starfieldConfig.ts`：集中参数及类型。
- `src/App.tsx`：持久挂载背景，其他路由采用较低显示强度，不更改运动。
- `src/pages/Home.tsx`、`src/components/home/ScrollChapter.tsx`：移除首页专属背景与旧动画逻辑，保留内容章节及照片动画。
- `src/styles/background.css`、`src/components/Layout.tsx`：黑色外层与透明布局，使用继承的表面配色变量区分黑底文字及白色卡片文字；保留品牌色和语义状态色。
- `src/pages/Admin.tsx`：后台外层透明；白色表单与编辑面板保留。
- `src/styles/home.css`：清除旧背景样式，保留独立的内容加载占位动画。
- `scripts/check-starfield.mjs`：执行真实组件 effect 的确定性生命周期与时间推进测试。

## 实际验证

### 构建与自动检查

- `npm run build`：通过，TypeScript与Vite均成功，日志见 `build.log`。
- 构建仍报告多处原有图片路径不存在、部分包大于500kB。背景改动未增加依赖，也未补造原内容资源。
- 8项现有检查通过：Projects.static、Photography.masonry、Blog.initialContent、AboutWechatDialog、ProjectImagePreview、ProjectLogoCover、Admin.headerIdentity、Admin.passwordChange。
- `node scripts/check-starfield.mjs`：通过。执行真实 effect，验证18单位/秒深度推进、50ms时间差上限、无指针/滚动监听、手机数量及尺寸变化保留深度、减少动态效果静止、后台取消RAF、恢复不追赶、StrictMode重放不重建颗粒且只有一个循环、卸载清理。另模拟300秒并验证回收后坐标有限、深度合法。
- 上述模拟不是300秒真实浏览器观察，也不是参考站动态测量。

## 限制与仍未验证项

- 缺少本地后端：有数据的博客正文、摄影作品预览及后台登录后状态未验证；没有用虚构数据冒充线上内容。
- 多处原有图片资源缺失，截图可能出现空图框。内容资产问题不在本次改动范围。
- 减少动态效果与页面隐藏/恢复已在真实 effect 的模拟浏览器环境测试；原生浏览器切换系统偏好、后台标签暂停时序未验证。
- 纯鼠标四角悬停未验证（当前接口未提供纯鼠标移动），不受鼠标驱动由代码和监听测试确认；实际拖选已验证。
- 无录屏；逐帧视觉流畅性及真实手机硬件上的性能未验证。
- 主要配色组合经计算，普通白色面板文字及黑底正文满足4.5:1目标；没有对所有页面、所有半透明/渐变背景和交互状态做完整对比度审计。
- 参考站准确方向、速度、尺寸、密度及透视未测量；后续调节集中配置即可，不应宣称完全一致。
